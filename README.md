### 🔒 2. Biometric WebAuthn Authentication & In-Place CMS
* **Fingerprint / Touch ID**: Hardware-level biometric authentication via `navigator.credentials` WebAuthn API.
* **Master PIN Fallback**: `tharun2026`.
* **In-Place CMS**: Over 40 text fields across headlines, bios, metrics, card summaries, and project details turn into live `contenteditable` inputs.
* **Floating Admin Toolbar**:
  * `Save All Changes`: Persists modifications to `localStorage` and disk via `/api/save`.
  * `Add Project`: Injects new dynamic project cards.
  * `Change Photo`: Uploads new profile or cover photos via `/api/upload-photo`.
  * `Export JSON`: Backs up full portfolio configuration.
  * `Reset`: Restores defaults.

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3 Glassmorphism (`backdrop-filter`), JavaScript (ES6+)
* **3D Spatial Graphics**: [Three.js](https://threejs.org/) (r128)
* **APIs**: WebAuthn API (Biometric Touch ID / Fingerprint), Web Audio API (Synthetic Cyber Audio)
* **Backend**: Multi-threaded Python HTTP Server with `/api/save`, `/api/data`, and `/api/upload-photo`

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/godwintharun3-source/Tharun_Godwin_Portfolio_3D.git
cd Tharun_Godwin_Portfolio_3D
```

### 2. Run the application
```bash
python3 server.py
```

### 3. Open in your browser
Navigate to:
```
http://localhost:8000
```
